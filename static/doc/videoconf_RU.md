### Конфигурация параметров видео

Документация: [VolcEngine Video Processing](https://www.volcengine.com/docs/82379/1393047)

| Название параметра       | Тип       | Обязательный/Необязательный | Описание                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                               | По умолчанию                  |
|--------------------------|-----------|-----------------------------|--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|-------------------------------|
| `VOL_VIDEO_MODEL`        | `String`  | Необязательный              | Модель генерации видео (Volcengine). Используется, если задана.                                                                                                                                                                                                                                                                                                                                                                                                                                                         | doubao-seedance-1-0-pro-250528 |
| `GEMINI_VIDEO_MODEL`     | `String`  | Необязательный              | Модель генерации видео (Gemini). Используется, если задана.                                                                                                                                                                                                                                                                                                                                                                                                                                                             | gemini-omni-1.1-flash         |
| `ALIYUN_VIDEO_MODEL`     | `String`  | Необязательный              | Модель генерации видео (Aliyun). Используется, если задана.                                                                                                                                                                                                                                                                                                                                                                                                                                                             | wan2.5-t2v-preview            |
| `RATIO`                  | `String`  | Необязательный              | Соотношение сторон видео (перечисление):<br>- **разрешение 480p** (короткая сторона 480p):<br>  - `16:9`: `[848, 480]`<br>  - `4:3`: `[640, 480]`<br>  - `1:1`: `[480, 480]`<br>  - `3:4`: `[480, 640]`<br>  - `9:16`: `[480, 848]`<br>  - `21:9`: `[1120, 480]`<br>- **разрешение 720p** (короткая сторона 720p):<br>  - `16:9`: `[1280, 720]`<br>  - `4:3`: `[960, 720]`<br>  - `1:1`: `[720, 720]`<br>  - `3:4`: `[720, 960]`<br>  - `9:16`: `[720, 1280]`<br>  - `21:9`: `[1280, 544]`<br> *Примечание:* для `21:9` короткая сторона фиксирована `544p` во избежание переполнения памяти. | `16:9`                        |
| `DURATION`               | `Integer` | Необязательный              | Длительность видео (секунды):<br>- `5`: текст-в-видео и изображение-в-видео<br>- `10`: только текст-в-видео                                                                                                                                                                                                                                                                                                                                                                                                              | `5`                           |
| `FPS`                    | `Integer` | Необязательный              | Кадровая частота. Перечисление:<br>- `24`                                                                                                                                                                                                                                                                                                                                                                                                                                                                               | `24`                          |
| `RESOLUTION`             | `String`  | Необязательный              | Разрешение видео (перечисление):<br>- `720p`: короткая сторона `720`<br>- `480p`: короткая сторона `480`<br> *Примечание:* `480p` для изображение-в-видео поддерживает только модель `seaweed`.                                                                                                                                                                                                                                                                                                                          | `720p`                        |
| `WATERMARK`              | `Boolean` | Необязательный              | Водяной знак в видео:<br>- `false`: без знака<br>- `true`: со знаком                                                                                                                                                                                                                                                                                                                                                                                                                                                     | `false`                       |
